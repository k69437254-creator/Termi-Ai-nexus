# TermiAI-Nexus — Flutter Android Starter (0.1.0)

هذه حزمة المصدر الأولى لبدء بناء تطبيق TermiAI-Nexus من مستودع GitHub باستخدام GitHub Actions.

## ما الذي يعمل في هذه النسخة؟

- تطبيق Flutter عربي باتجاه RTL وهوية داكنة زرقاء/سوداء.
- صفحات رئيسية للمشاريع والوكلاء ومراقبة العمليات والإعدادات.
- إدخال طلب مشروع وحفظه كمسودة داخل ذاكرة التطبيق أثناء الجلسة.
- عرض أدوار الفريق وحالة الخدمات غير المنفذة بوضوح.
- اختباران أوليان للتحقق من ظهور الواجهة وسلوك حفظ المسودة.
- Workflow في `.github/workflows/android-apk.yml` ينشئ ملفات Android، ثم يشغّل التحليل والاختبارات ويبني APK ويرفعه كـ Artifact.

## ما الذي لم يُنفّذ بعد؟

هذه ليست النسخة النهائية من TermiAI-Nexus. لا تتضمن هذه الحزمة تنفيذًا فعليًا لـ:

- Debian/PRoot أو Bash أو PTY.
- مدير الوكلاء أو تنفيذ المهام أو الذاكرة الدائمة.
- الاتصال الفعلي بمحرك Aram AI على `127.0.0.1:8765`.
- Git المحلي أو تكامل GitHub داخل التطبيق.
- العالم ثلاثي الأبعاد الحقيقي أو خدمة تعمل في الخلفية.
- التخزين الدائم للمشاريع أو الاستعادة بعد إعادة التشغيل.

لا تعرض الواجهة هذه الأجزاء على أنها تعمل؛ تظهر حالتها «غير منفذ» أو «غير مربوط» إلى أن تُبنى وتُختبر.

## طريقة وضع الملفات في المستودع

1. فك ضغط الملف.
2. ارفع **محتويات مجلد `TermiAI-Nexus-Starter`** إلى جذر المستودع `Termi-Ai-nexus`، بجانب وثيقة المواصفات الموجودة، وليس داخل مجلد فرعي.
3. نفّذ Commit وPush إلى الفرع `main`.

**اختصار عبر Termux:** بعد فك الضغط، شغّل السكربت المرفق من مجلد الحزمة مع تمرير مسار نسخة المستودع المحلية:

```bash
bash push_to_github.sh /path/to/Termi-Ai-nexus
```

يتحقق السكربت من أن `origin` هو المستودع الصحيح وأن الفرع `main`، ثم ينسخ ملفات التطبيق وينفذ Commit وPush. لا تحذف أو تستبدل وثيقة المواصفات الموجودة في المستودع.

## الحصول على APK من GitHub Actions

1. افتح المستودع على GitHub.
2. افتح تبويب **Actions**.
3. اختر **Build TermiAI-Nexus APK** وافتح آخر تشغيل ناجح.
4. من قسم **Artifacts** نزّل `TermiAI-Nexus-APK-...`.
5. فك ضغط Artifact، ثم ثبّت ملف `app-release.apk` على هاتف Android.

يمكن تشغيل Workflow يدويًا من زر **Run workflow**، كما يعمل تلقائيًا عند دفع تحديث إلى `main`.

## معلومات البناء

- Flutter: stable channel في بيئة GitHub Actions.
- Android package id: `com.aramaoyal.termiai_nexus`.
- Build type: Release APK للتجربة، يستخدم إعداد التوقيع الافتراضي الذي يولّده Flutter ولا يمثل مفتاح نشر رسميًا. إعداد مفتاح توقيع إنتاجي خطوة مستقلة لاحقًا.
- لا حاجة إلى مفاتيح Secrets لبناء APK الاختباري.
